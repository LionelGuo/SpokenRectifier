| 用例 | 类别 | 现象 | 期望 |
| --- | --- | --- | --- |
| short-number | 保留失败+残留 | "一共三份文件" — 数字未规范化 | "3份"(轻修契约含数字规范化) |

## 用例断言的既定裁量(评分语义,非缺陷)

- 大小写属语体范畴(ADR-0004):不在术语词表内的英文词(envoy/rust)
  任意大小写均判通过。
- 口语数字的规范化形态在 convey 组内多形态任一即可(60万/六十万),
  仅规则原文例举的形态(30%、6月21日)作严格 preserve。
- 真机观察:模型会把"十点"写成"10点"、"发群里"写成"发到群里" —
  断言按语义组宽进。

## 运行

```
cargo run -p sr-replay --bin sr-eval                    # 全量,报告打印 stdout
cargo run -p sr-replay --bin sr-eval -- --only short-   # 只跑某前缀/某条
cargo run -p sr-replay --bin sr-eval -- --report out.md # 另存 markdown
```

注意:真 LLM 逐条调用,存在采样方差;个别用例偶发失败属正常,连续
失败才是回归信号。如需定时(默认不设,按需手动跑):`scripts/nightly-eval.sh`(报告落
`.scratch/eval/`,按日归档;该目录不入库,本机经 `.git/info/exclude`
排除)。
